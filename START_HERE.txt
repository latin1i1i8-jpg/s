┌─ 🎯 가장 빠른 방법 (권장) ─────────────────────────────────────────────┐
│                                                                           │
│  1. GitHub에 새 저장소 만들기                                           │
│     → https://github.com/new                                            │
│     → Repository name: JarvisMode                                       │
│     → Add a README.md: 체크 해제                                        │
│                                                                           │
│  2. 이 폴더를 GitHub에 올리기                                          │
│     → bash github_setup.sh https://github.com/username/JarvisMode.git   │
│     (또는 SETUP.md에서 수동 방법 참고)                                  │
│                                                                           │
│  3. GitHub Actions가 자동 빌드 (2~3분)                                  │
│     → Actions 탭 → Artifacts → jarvis-debug-apk.zip 다운로드           │
│                                                                           │
│  4. 폰에 설치                                                            │
│     → adb install -r app-debug.apk                                      │
│                                                                           │
└───────────────────────────────────────────────────────────────────────────┘

│  $ gradle wrapper --gradle-version 8.9   (최초 1회만)                   │

│  > gradlew assembleDebug                                                │
│                                                                           │
